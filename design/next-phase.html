This is what the extension already saves as report.json. The server validates the version and the shape, then stores it as is.

Decisions before building

  • Who may submit: sign-in on the company domain, one report per person per month, resubmitting replaces it. The server takes the name from the sign-in and ignores the "user" field in the file.
  • What leaves the laptop: report fields and token counts only. Prompts stay local. The user sees the exact file before sending.
  • Admin hook: runs on the admin's Claude Code, reads stored reports, and writes the short summary shown on top. The data itself is never rewritten.
  • Policy: the report is mandatory and due on the 1st. The dashboard marks who is missing, so a lead does not have to chase by hand.
